# TC07 — Complete a Wi-Fi-only upload after connecting to Wi-Fi

Suite: Offline and Network Settings

Verify that an upload initially prevented by the Wi-Fi-only setting can be completed after a Wi-Fi connection becomes available, without disabling the restriction.

## Preconditions

1. Environment: ENV-001 — Samsung Galaxy S24 FE, Android 16, One UI 8.5, Google Drive 2.26.387.

2. The user is signed in to Google Drive.

3. The Google account has sufficient available storage.

4. A readable PDF smaller than 1 MB is stored locally as TC07_R01_document.pdf.

5. The destination folder QA-Connectivity-Lab exists and contains no file with that name.

6. No other uploads are pending.

7. Working mobile data and a working Wi-Fi connection are available.

8. The desktop browser has independent internet access and is signed in to the same Google account.

9. The device's initial connectivity and Wi-Fi-only transfer settings are recorded for restoration after the test.

## Procedure

| Step | Action | Expected result |
|---|---|---|
| 1 | Open the local PDF and note its page count and content. | The PDF opens correctly and its content is available for comparison. |
| 2 | Enable Google Drive's "Transfer files only over Wi-Fi" setting. Disable Wi-Fi and enable mobile data. | The restriction is enabled and the phone is connected through mobile data only. |
| 3 | Open QA-Connectivity-Lab and attempt to upload TC07_R01_document.pdf. Decline or dismiss any request to allow uploading over mobile data. | The upload does not proceed without Wi-Fi. The app indicates a waiting state, a Wi-Fi requirement, or requests authorization. |
| 4 | Observe for 30 seconds, record the app status, and refresh the destination folder on the desktop. | The upload is not reported as completed and the file is absent from the cloud folder. |
| 5 | Enable Wi-Fi and confirm internet access. Disable mobile data. Keep the Wi-Fi-only transfer setting enabled. | The phone has working Wi-Fi connectivity and the transfer restriction remains enabled. |
| 6 | Return to Google Drive and observe the upload. If needed, use an available retry or upload action without starting a duplicate active upload. Record whether recovery was automatic or manual. | The upload can proceed over Wi-Fi without disabling the restriction. |
| 7 | Wait for completion and record the final status. | The file appears with no pending upload or error indicator. |
| 8 | Refresh the destination folder on the desktop and open the uploaded PDF. | Exactly one file named TC07_R01_document.pdf is listed. It opens, and its page count and visible content match the original. |

## Postconditions

1. Keep the uploaded file in the destination folder until evidence collection is complete.

2. Ensure no upload from this case remains pending.

3. Restore the device's initial connectivity and transfer settings after evidence collection.
