# TC03 — Upload a PDF file over mobile data

Suite: Baseline Uploads

Verify that a PDF can be uploaded over mobile data when Wi-Fi-only transfers are disabled, and that the uploaded content matches the local original.

## Preconditions

1. Environment: ENV-001 — Samsung Galaxy S24 FE, Android 16, One UI 8.5, Google Drive 2.26.387.

2. The user is signed in to Google Drive.

3. Wi-Fi is disabled and mobile data is enabled with working internet access.

4. Google Drive's "Transfer files only over Wi-Fi" setting is disabled.

5. The Google account has sufficient available storage.

6. A readable PDF smaller than 1 MB is stored locally as TC03_R01_document.pdf.

7. The destination folder QA-Connectivity-Lab exists and contains no file with that name.

8. The same Google account is accessible through a desktop browser for verification.

9. The mobile carrier and observed network type are recorded in the execution notes.

## Procedure

| Step | Action | Expected result |
|---|---|---|
| 1 | Open the local PDF and check its page count and content. | The PDF opens correctly. Its page count and content are noted for comparison. |
| 2 | Confirm that Wi-Fi is disabled, mobile data is enabled, and Wi-Fi-only transfers are disabled in Google Drive. | The device is configured to upload through mobile data. |
| 3 | Open Google Drive and navigate to QA-Connectivity-Lab. | The destination folder opens successfully. |
| 4 | Start a file upload and select TC03_R01_document.pdf from local storage. | The upload starts without requiring a Wi-Fi connection. |
| 5 | Wait for the upload to finish and observe the app status. | The file appears in the destination folder with no pending upload or error indicator. |
| 6 | Refresh the destination folder in Google Drive on the desktop browser. | Exactly one file named TC03_R01_document.pdf is listed. |
| 7 | Open the uploaded PDF on the desktop and compare it with the local original. | The PDF opens, and its page count, text and visible content match the original. |

## Postconditions

1. Keep the uploaded file in the destination folder until evidence collection is complete.

2. Restore the device's previous connectivity and transfer settings after evidence collection.
