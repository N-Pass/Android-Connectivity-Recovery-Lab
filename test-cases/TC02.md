# TC02 — Upload an image file over Wi-Fi

Suite: Baseline Uploads

Verify that an image uploaded over Wi-Fi is available in the destination folder and its visible content matches the local original.

## Preconditions

1. Environment: ENV-001 — Samsung Galaxy S24 FE, Android 16, One UI 8.5, Google Drive 2.26.387.

2. The user is signed in to Google Drive.

3. Wi-Fi is connected and mobile data is disabled.

4. The Google account has sufficient available storage.

5. A valid JPG image without personal information is stored locally as TC02_R01_image.jpg, preferably between 2 and 5 MB.

6. The destination folder QA-Connectivity-Lab exists and contains no file with that name.

7. The same Google account is accessible through a desktop browser for verification.

8. The current Wi-Fi-only transfer setting is recorded in the execution notes.

## Procedure

| Step | Action | Expected result |
|---|---|---|
| 1 | Open the local image and inspect its orientation and visible content. | The image opens correctly. Its orientation and content are noted for comparison. |
| 2 | Open Google Drive and navigate to QA-Connectivity-Lab. | The destination folder opens successfully. |
| 3 | Start a file upload and select TC02_R01_image.jpg from local storage. | The upload request is accepted without an error. |
| 4 | Wait for the upload to finish and observe the app status. | The image appears in the destination folder with no pending upload or error indicator. |
| 5 | Refresh the destination folder in Google Drive on the desktop browser. | Exactly one file named TC02_R01_image.jpg is listed. |
| 6 | Open the uploaded image on the desktop and compare it with the local original. | The image opens with matching orientation and visible content, without unexpected cropping or visible corruption. |

## Postconditions

Keep the uploaded file in the destination folder until evidence collection is complete.
