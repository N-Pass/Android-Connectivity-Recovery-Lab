# TC06 — Respect Wi-Fi-only uploads when using mobile data

Suite: Offline and Network Settings

Verify that Google Drive does not upload a PDF over mobile data when the Wi-Fi-only transfer setting is enabled and no override is authorized.

## Preconditions

1. Environment: ENV-001 — Samsung Galaxy S24 FE, Android 16, One UI 8.5, Google Drive 2.26.387.

2. The user is signed in to Google Drive.

3. The Google account has sufficient available storage.

4. A readable PDF smaller than 1 MB is stored locally as TC06_R01_document.pdf.

5. The destination folder QA-Connectivity-Lab exists and contains no file with that name.

6. No other uploads are pending.

7. Mobile data has working internet access.

8. The desktop browser has independent internet access and is signed in to the same Google account.

9. The device's initial connectivity and Wi-Fi-only transfer settings are recorded for restoration after the test.

## Procedure

| Step | Action | Expected result |
|---|---|---|
| 1 | Enable Google Drive's "Transfer files only over Wi-Fi" setting and capture evidence of the setting. | The Wi-Fi-only transfer setting is enabled. |
| 2 | Disable Wi-Fi and enable mobile data. Ensure no alternative connection is active. | The phone has internet access through mobile data only. |
| 3 | Open Google Drive and navigate to QA-Connectivity-Lab. | The destination folder is accessible. |
| 4 | Attempt to upload TC06_R01_document.pdf. If prompted to allow mobile data for this upload, decline or dismiss the prompt. | The upload does not proceed over mobile data without explicit authorization. The app indicates a Wi-Fi requirement, a waiting state, or requests permission to override the restriction. |
| 5 | Keep Wi-Fi disabled and observe for 30 seconds. Record the exact message and upload state. | The upload is not reported as completed while the Wi-Fi-only restriction remains active. |
| 6 | Refresh the destination folder in the desktop browser. | TC06_R01_document.pdf is not present in the cloud folder. |
| 7 | Open the original PDF from local storage on the phone. | The original PDF remains available and readable. |

## Postconditions

1. Capture the app status and desktop verification before changing connectivity or transfer settings.

2. Cancel the pending upload if that option is available.

3. Restore the device's initial connectivity and transfer settings.

4. If the upload completes during cleanup, remove only TC06_R01_document.pdf from the test folder after evidence collection.

5. Ensure no upload from this case remains pending.
